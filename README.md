Finance Management System | Python, Tkinter, MySQL

Developed a desktop application to track income and expenses and generate an instant profit/loss audit. Built with a Tkinter GUI and a MySQL database, it records transactions, updates totals automatically, and displays income, expenses, and balance in a live table. The Audit feature calculates the net balance and reports whether the business is in profit, loss, or break-even.

Tech stack: Python, Tkinter, PyMySQL, MySQL

Key skills: GUI development, database integration, error handling, event-driven programming
